# Prompts dos palitos — todas as eras

Um prompt por era. Gere **só o palito horizontal**: as diagonais da torre são montadas pelo jogo a partir dele,
garantindo tamanho e textura idênticos. Gere cada um numa conversa nova do ChatGPT e me mande a imagem com o nome da era.

As cores são as da paleta do jogo para cada material (o jogo ajusta o restante).

## Era 02 — Palito de Dente

```
Create ONE pixel art game sprite on a fully TRANSPARENT background (real alpha channel, background completely removed: no white, no checkerboard, no ground, no shadow, no text, no border).

The sprite: a wooden TOOTHPICK, smooth pale birch wood, BOTH ends sharply pointed (tapering to 1 pixel), no head, lying perfectly HORIZONTAL, seen from the front and slightly from above.

RULES:
- True low-resolution pixel art: the object is exactly 34 pixels long and 3 pixels thick. Each art pixel is a perfect square block of identical size (scale it up uniformly, every art pixel = 16x16 screen pixels).
- 3 rows of color along the length: top row #FFF1D0 (light), middle row #F0D9A8 (base), bottom row #C9A46A (shadow). Light comes from the top-left.
- Extra detail colors allowed: none.
- No anti-aliasing, no gradients, no blur, no noise, no outline glow. Flat colored pixels only.
- Same style as a classic 16-bit SNES game item sprite.

Output: one PNG with transparent background containing only this single horizontal sprite, centered.
```
